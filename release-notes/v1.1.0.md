# Paperling 1.1.0 — full release notes

Released 2026-10-02. The short version is in the [changelog](../CHANGELOG.md) and on the [release page](https://github.com/Razee4315/Paperling/releases/tag/v1.1.0); this page has everything.

Paperling 1.1 is about the basics. Opening a note, reading it, changing a sentence and saving it are what everyone does, and those steps now work the way you would expect from the first minute.

## If you are updating from 1.0.x

- **Your settings stay as they are.** Autosave, "Open files in reader mode", the formatting toolbar, spell check and your theme are not changed by the update. The new defaults below apply to fresh installs; you can switch any of them on in Settings.
- **Android** installs over 1.0.51 normally. (Only the 1.0.50 → 1.0.51 step needed a reinstall.)
- **Desktop** updates through the in-app updater as usual.

## Reading and editing

- **Edit while you read.** In Reader, double-click a sentence to fix it in place. Paragraphs, headings, lists, task lists and quotes are editable, with bold, italic, strike, code and link. Wikilinks, tags, highlights and inline math inside them are kept exactly as written. Escape or "Stop editing" leaves. Tables, images, code blocks and callouts are still edited in Code or Split view. (#213)
- **Notes open ready to read** on new installs, and **each tab remembers its own view**: putting one note into the editor no longer flips the others.
- **Hide Markdown symbols** (optional, Settings → Editor): in the editor, `#`, `**`, backticks and link syntax show only on the line you are editing, and headings are sized.
- **Zoom.** `Ctrl +`, `Ctrl -`, `Ctrl 0` and `Ctrl`+wheel zoom the text from 50% to 300%. Also in the settings menu.
- New installs get the **formatting toolbar and spell check** on.

## Saving

- **A Save button** in the title bar, and the status bar's "Unsaved" is clickable.
- **Autosave is on for new installs.** It saves a moment after you stop typing, only for files that already have a name; a new note still asks once where to live. It never overwrites a file that changed on disk without asking.
- **Reopen last session** can be turned off. Unsaved work is always recovered either way, and the note you opened appears before background tabs finish loading. (#228)

## Files and folders

- **Open a folder** from the welcome screen, the More menu, the Files panel, the command palette, or by dropping a folder on the window. It stays the Files root and the search scope. (#227)
- **Files and Outline side by side.** Files docks on the left, Outline and Backlinks on the right. (#226)
- **Files stays open** after you open a note on desktop. (#225)
- `.mdown`, `.mkd` and `.mdx` open like `.md`, and a double-clicked `README.MD` (upper-case extension) now opens.

## Look and feel

- **Follows your system's light or dark setting** on new installs (Paper by day, Graphite by night). Pick "System" among the themes to turn it on yourself.
- **A calmer title bar**: New, Open, Save, Export and a More menu (Open folder, Find, Save As, Print).
- **A compact settings menu**: theme swatches, one font picker, text size and zoom, without scrolling.
- **Settings → Editor is grouped** into Writing, Saving and files, and Reading.
- **Buttons respond.** Title-bar and window buttons highlight on hover and press in when clicked, on every theme.
- **The welcome tour** now covers reading and editing, saving, and appearance.
- Remote `https` images and badges render in the preview, with a setting to turn them off and load them per image. (#224)

## AI

- **Edit a message you sent and regenerate** the latest reply. A failed or stopped retry keeps the previous answer. (#230)
- Expand / Shorten / Rewrite **stream and no longer time out** after 60 seconds on local models. (#229)
- Agent mode **explains when the model returned no usable edit** and offers the reply as a diff, instead of doing nothing. (#231)

## Fixed

- Touchscreen Windows and Linux PCs opened the phone layout, which has no title bar, so the window could not be moved or closed. (#206)
- Window buttons stay visible in a narrow window. (#241)
- The active Read / Split / Code button is no longer a white pill in dark themes. (#232)
- macOS: double-clicking a `.md` in Finder opens that file. (#250)
- Android: "Open from device…", "Save to Downloads" and "Export as HTML" work again, and the editor stays above the on-screen keyboard. Two different files with the same name no longer share one working copy. (#252, #253, #254)
- PDF export no longer leaves a temporary HTML file behind on Windows. (#214)
- Editing a numbered list in Reader no longer re-spaces every item.
- The Nix package builds again. (#212)
