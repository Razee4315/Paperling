# Paperling 1.2.0 — full release notes

Released 2026-10-31. The short version is in the [changelog](../CHANGELOG.md) and on the [release page](https://github.com/Razee4315/Paperling/releases/tag/v1.2.0).

Paperling 1.2 opens more of your files, keeps earlier versions of them, and fills in the everyday gaps people noticed coming from other editors.

## If you are updating from 1.1.x

- **Your settings stay as they are.**
- **Android** installs over 1.1.x normally.
- **Desktop** updates through the in-app updater as usual.
- **File history starts now.** It saves versions from this update onward, so older edits aren't in it. You can turn it off in Settings → Editor.

## Opening more files

- **HTML files.** `.html` pages open rendered with their own styles, and images and stylesheets next to the file load too. A page opens in a locked-down view: scripts, forms and popups don't run, and it can't reach the rest of the app. Code mode edits the source. Reader is view-only for HTML, because Reader editing works in Markdown. (#295)
- **UTF-16 and Windows-1252.** PowerShell output, Notepad "Unicode" files and old Windows notes used to fail with an error. They now open normally and save back in the same encoding, byte for byte, with their line endings kept. The status bar shows the encoding of any file that isn't plain UTF-8. Find in Files and backlinks read these files too. (#297)
- **Nothing is damaged quietly.** If you type a character the file's encoding can't hold, an explicit save asks before converting to UTF-8. Autosave never asks: it tells you, and your text stays in the editor until you save. Damaged files, UTF-32 and binary files are refused with a reason instead of being opened and corrupted.

## Keeping your work

- **File history.** Paperling keeps earlier versions of each file on this computer: up to 40 versions per file for 30 days, for files up to about 2 MB. Open **File history** from the command palette to compare a version with your current text and restore it. A restore is an ordinary edit, so you can undo it, and nothing is written to disk until you save.
- **Notes refresh on their own.** A note changed by another program (a terminal, a sync tool, an agent) updates within a couple of seconds while Paperling is on screen. If you have unsaved edits, Paperling asks which version wins. (#263)
- **Images update too.** A picture that changed on disk shows its new version when you come back to the window, without a restart. (#266)
- **Safer saves.** Autosave no longer risks overwriting a change made by another program on files with an unusable modified time, such as some network and FAT drives.

## Writing and editing

- **Fold** headings, lists and code blocks from the gutter or with `Ctrl+Shift+[` and `Ctrl+Shift+]`. Fold all and Unfold all are in the palette. You can turn folding off in Settings.
- **Emoji shortcodes.** `:rocket:` renders as an emoji, and typing `:roc` offers matches.
- **Table of contents.** Run **Insert or update table of contents** or type `/toc` for a list that works on GitHub and updates when you run it again. A `[TOC]` line also renders one in the preview.
- **Text commands** in the palette: sort lines A to Z or Z to A, remove duplicates, change case, and insert the date or the date and time. Sorting works on the lines you select.
- **New shortcuts.** `Alt+Z` toggles word wrap, `Ctrl+Shift+X` is strikethrough and ``Ctrl+` `` is inline code. All of them can be changed in Settings.

## Finding your files

- **Options → Recent.** Open a recent file from anywhere, with the mouse or the keyboard. (#281)
- **Recent folders** on the welcome screen and in the palette.
- **A filter in the Files panel** for folders with more than seven entries. Enter opens the first match.
- **Tabs.** Move left and Move right are in the tab menu on every platform, and dragging tabs now works on macOS. (#263)

## Reading and sharing

- **Wide code blocks** use the free space beside the reading column instead of being cut off. (#294)
- **Copy as rich text** for Word, Gmail and Google Docs, and **Copy as HTML**, from the Export menu or the palette.
- **Custom CSS** in Settings → Editor. It applies to the whole app, so a mistake can hide parts of it; clearing the box puts everything back.
- **Ordered lists** no longer clip their numbers at larger text sizes. (#270)
- **Copying from Reader** no longer pastes icon names like "link". (#267)

## Privacy and security

- **Load remote images off now covers everything.** Mermaid diagrams and AI replies respect the setting, as document images already did.
- **AI replies.** Links open in your browser, and anything that looks like an API key is masked in error messages.
- **The AI privacy note in Settings is now accurate:** messages from the AI panel send the whole open document plus your chat history.
- **Mermaid diagrams** get a second sanitising pass.
- **Dependencies** were updated for the published RustSec advisories in rustls, rustls-webpki and tokio.

## Good to know

- **HTML:** links in a page don't open yet, Export and Print are off, and find searches the source. Remote stylesheets are blocked.
- **File history** doesn't follow a file when you rename it.
- **Encodings:** Save As writes UTF-8. Other legacy encodings such as Shift-JIS open through Windows-1252, so the letters look wrong, but the bytes are kept when you save unless you type something Windows-1252 can't hold.
