# Paperling 1.3.0 — full release notes

Released 2026-11-26. The short version is in the [changelog](../CHANGELOG.md) and on the [release page](https://github.com/Razee4315/Paperling/releases/tag/v1.3.0).

Paperling 1.3 speaks eight languages, makes whole-folder navigation and embedded images feel seamless, fixes Android file write-back, and hardens performance, contrast, accessibility, and file safety end-to-end.

## If you are updating from 1.2.x

- **Your settings stay as they are.**
- **Interface language defaults to *Follow system*** if you haven't picked one yet, matching Theme's *System* mode, and can be switched manually anytime in Settings → Appearance.
- **Android** installs over 1.2.x normally.
- **Desktop** updates through the in-app updater as usual.

## Languages

- **Eight UI languages.** English, 简体中文, Español, Français, Deutsch, 日本語, 한국어, and Português are built in, covering menus, toolbars, settings, shortcut names, dialogs, notifications, and the cheatsheet. (#308)
- **Live system language detection.** Leaving Language on *Follow system* follows your OS display language automatically and updates live if it changes.
- **Non-ASCII and CJK image paths.** Relative image paths with percent-encoded Unicode or CJK characters decode properly and render instead of breaking on load.

## Working across folders

- **Recursive Quick Switcher.** Opening Quick Switcher inside a workspace now finds Markdown and text files across nested subfolders, not just the root directory.
- **Nested `[[wikilinks]]`.** `[[Projects/Roadmap]]` and nested links resolve cleanly across folders, and links from nested notes like `[[Welcome]]` also match open parent tabs when no folder workspace is open.
- **Expandable Files panel.** Click a folder chevron to expand or collapse subfolders inline right inside the Files tree.
- **More file actions.** Right-click items in the Files panel to **Duplicate**, **Copy path**, or **Reveal** them in Explorer / Finder / your system file manager.

## Images and preview

- **Drop images right into a note.** Dragging image files onto Paperling copies them safely into `./images/` beside the note (preventing overwrites and path escapes) and inserts clean Markdown image links.
- **`![[image]]` embeds and sizing.** Wikilink image embeds now pass sanitization safely and support `![[image|WxH]]` (or width-only `![[image|W]]`) dimensions in preview.
- **Smoother diagrams & math.** Mermaid renders through a single queued pipeline so rapid edits no longer drop or race diagrams, local image blobs stay retained during swaps, and extreme KaTeX macros hit bounded limits rather than hanging the tab.
- **Tighter HTML exports.** Exported HTML keeps a strict Content Security Policy without `unsafe-inline` scripts and sanitizes inline SVG diagrams cleanly.

## Writing, shortcuts, and AI

- **Auto-closing brackets & quotes toggle.** Turn automatic closing pairs on or off in Settings → Editor → Writing. (#313)
- **Configurable RTL/LTR text-direction shortcut.** Rebind or disable the Windows/Linux `Ctrl+Right/Left Shift` text-direction shortcut in Settings → Shortcuts or Settings → Editor → Writing. (#293)
- **Inline AI Explain & Translate language picker.** Selection assist adds **Explain** alongside rewrite, shorten, expand, and continue, and lets you pick any of the eight languages directly when using **Translate**.
- **Everyday editing fixes.** Safer smart paste (TSV and rich HTML), table toolbar and code-editor guards, Unicode/regex find and Reader `<details>` search fixes, and stricter frontmatter/math parsing.

## Android

- **Write edits back to your device.** Save and Autosave now write directly back to the original SAF / Downloads document instead of only updating the app's disposable cache copy. Read-only or failed write-backs keep your buffer marked unsaved so closing the tab warns rather than quietly losing work. (#305)
- **Android Save As & Back button.** Improved Save As flows using atomic `MediaStore` `IS_PENDING` saves (up to a 50 MB import guard) and cleaner Back button navigation through overlays.

## Readability, accessibility, and performance

- **WCAG AA contrast across all seven themes.** Text and secondary UI tokens meet `>= 4.5:1` contrast across Dark, Graphite, Nord, Midnight, Light, Paper, and Dracula.
- **Keyboard & menu polish.** Dialogs retain keyboard focus cleanly, right-click context menus portal out of clipped sidebars so items never truncate, and decorative menu icons stay hidden from screen readers.
- **Faster editing & startup.** Hidden preview panes pause work in Code mode, heavy CodeMirror / merge / Vim / tour bundles load lazily on demand, sidebars memoize cleanly, and crash-recovery backups and file history stay bounded cleanly in storage.

## Security and reliability

- **Atomic saves & tab handoffs.** Switching or closing tabs flushes live editor changes synchronously before saving, external-change detection rolls back stale modification times accurately, autosaves cancel cleanly on close/revert, and BOM-encoded files preserve encoding across retargets.
- **Hardened Rust file & AI backend.** Atomic image writes with extension validation, two-step case-only renames on case-insensitive filesystems (Windows/macOS), symlink-safe directory walks, non-blocking PDF export waits, `0o600` private storage for mobile AI keys, disabled HTTP redirects and a 16 MB response cap in the AI client, and updated Rust dependencies (`cookie`, `url`, `async-executor`) clearing open RustSec advisories.

## Good to know

- **Dropping image files** copies into `./images/` beside a saved note; unsaved notes without a path ask or require saving first.
- **File history** still doesn't follow a file across renames outside or inside the panel.
- **Unsigned desktop installers:** Windows SmartScreen and macOS Gatekeeper notes in the README still apply to first-time desktop installs, while in-app auto-updates remain minisign-verified before extraction.
