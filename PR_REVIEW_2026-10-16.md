## Findings and repairs

1. **P1 — Android version mismatch:** `package.json:35` declares `"@tauri-apps/plugin-fs": "^2.7.0"`; `src-tauri/Cargo.lock:4618` must also resolve `tauri-plugin-fs` to `2.7.0`. The separate PRs updated opposite sides, causing Tauri's Android compatibility check to fail. Both changes now land together. Evidence: failed runs 38525733193 and 38525770997.
2. **P1 — TLS dependency advisories:** `src-tauri/Cargo.lock:3723`, `name = "rustls"`, previously resolved to `0.23.45`. Cargo-deny reported RUSTSEC-2026-0346 through RUSTSEC-2026-0349. A narrow `cargo update -p rustls --precise 0.23.46` updated the version and checksum. No advisory suppressions were added. Existing PR check results predated the advisories, so green historical checks were insufficient.
3. **P2 — Nix build failure:** `flake.nix:28`, `x86_64-linux = "sha256-..."`, still described the old frontend dependency closure. Updated to `sha256-rovlh4qkQjAaEB4CcqsiEYZ1XJZlqNjClfIDWg6cbSU=` from Nix run 38525739502. This restores reproducible installation rather than bypassing hash validation.
4. **P2 — Recent-menu usability:** `src/components/MoreMenu.tsx:301`, `onClick={() => openRecentSubmenu(true)}`, replaces toggling after hover, which made a normal click close the submenu. Menu-local arrow/Home/End handling prevents focus escaping into the parent. Left/Escape return one level, empty menus remain keyboard accessible, and hover dismissal restores focus. `src/components/MoreMenu.tsx:72` clamps the fly-out to the viewport and puts it below the trigger when neither side fits; the resize handler at line 116 remeasures after layout settles. Regression coverage: `src/components/MoreMenu.test.tsx`.
5. **P2 — CI cache inflation:** `.github/workflows/ci.yml:56`, `save-if: ${{ github.ref == 'refs/heads/main' }}`, lets PRs restore shared caches without creating per-PR copies. The Windows/macOS Test Build jobs use the same rule. Android additionally allows its dedicated development branch. Its separate debug-keystore cache remains untouched because it preserves APK signing identity.
6. **P3 — Docs integration conflict:** `docs/package.json:33` and the matching workspace entries in `docs/bun.lock` conflicted between the two updates. Preserve TypeScript `~6.0.3`, Astro `^7.3.8`, Prettier `^3.9.10` and its Astro plugin `^1.1.1`; frozen installation verifies consistency.
